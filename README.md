# 🐱 Esse Gato Sou Eu

> Aplicação web desenvolvida com **Python (Flask)** e **JavaScript** para consumo de API externa de gatos, gerando imagens e conteúdos felinos de forma dinâmica.

🔗 **Acesse o repositório:** [https://github.com/gabrielcamargogsilva/Esse-gato-sou-eu](https://github.com/gabrielcamargogsilva/Esse-gato-sou-eu)

---

## 📌 Sobre o Projeto

O **Esse Gato Sou Eu** é um projeto interativo focado na prática de desenvolvimento web full-stack simples e consumo de APIs RESTful. A aplicação utiliza um back-end construído em **Python com Flask** para gerenciar rotas e integrar requisições assíncronas no front-end, permitindo ao usuário carregar novas imagens e características felinas a cada interação.

---

## 🚀 Funcionalidades

- 🎲 **Geração Dinâmica:** Requisição de novas fotos/conteúdos felinos com apenas um clique.
- 🐍 **Back-end com Flask:** Servidor em Python responsável por gerenciar rotas e renderizar as páginas/requisições.
- ⚡ **Requisições Assíncronas:** Uso de `fetch` / `async/await` no front-end para buscar dados em tempo real sem reload.
- 🖼️ **Exibição Responsiva:** Renderização adaptada das imagens e informações para diferentes telas.

---

## 🛠️ Tecnologias Utilizadas

* **Python:** Linguagem base para o servidor back-end.
* **Flask:** Microframework Python para gerenciamento de rotas e rotinas do servidor.
* **HTML5 & CSS3:** Estruturação semântica, estilização e layout responsivo.
* **JavaScript (ES6+):** Lógica de consumo da API externa e manipulação da DOM.
* **The Cat API (ou equivalente):** Provedor dos dados e imagens felinas.

## 📂 Como Executar o Projeto Localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/gabrielcamargogsilva/Esse-gato-sou-eu.git
   ```
2. Acesse o diretório do projeto:
   ```bash
   cd Esse-gato-sou-eu
   ```
3. Crie e ative um ambiente virtual (opcional, mas recomendado):
   ```bash
   python -m venv venv
   # No Windows:
   venv\Scripts\activate
   # No Linux/macOS:
   source venv/bin/activate
   ```
4. Instale as dependências:
   ```bash
   pip install flask
   ```
5. Execute a aplicação Flask:
   ```bash
   python app.py
   ```
6. Acesse em seu navegador: `http://localhost:5000`
